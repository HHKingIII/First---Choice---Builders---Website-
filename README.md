# 1st Choice Builders Website

This is a free, phone-friendly static website starter.

## Pages
- index.html — Home
- services.html — Services
- projects.html — Projects
- about.html — About
- estimate.html — Free Estimate / Contact

## Important
The estimate form currently opens the visitor's email app using mailto. This keeps the site free and requires no paid form service.

For automatic online form submissions later, connect a free form backend or your own backend.

For card payments, add Stripe Checkout or a Stripe Payment Link once the Stripe account is ready. Do not put secret payment keys in these files.

## Deploying from a phone
The easiest path is to upload the folder to a free static hosting service or a Git repository and deploy it from there. The site itself does not require a paid server.

## Replace images
All current images are in assets/. Replace them with better project photos anytime without changing the page structure.
